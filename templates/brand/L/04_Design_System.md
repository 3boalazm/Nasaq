# {{name}} — 04 Design system (size L)

Phases: System, then Applications. Purpose: turn the chosen identity into rules, tokens, templates and real applications that other people can use without the author.

## 1 Guidelines

- Guide contents: strategy summary, every component in module 03, layout grid, application rules, misuse, file index.
- One source of truth for tokens (colour, type, spacing). The guide and the files read from it.
- Sub-brand rules follow the architecture in module 02.
- Stretch test: the system applied to the smallest, the largest and the most text-heavy application in scope.
- The guide is delivered as a PDF and as an editable version the client can update.
